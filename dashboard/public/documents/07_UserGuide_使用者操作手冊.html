使用者操作手冊

系統名稱：微感監測中心 (TC IoT Center) 文件版本：v1.0.0 作者：PST-Tim 日期：2026-07 目標讀者：一般使用者（稽查人員、管理員）

1. 系統登入

1
開啟瀏覽器（建議使用 Chrome 或 Edge 最新版），前往系統網址：https://tc-iot-center.vercel.app
2
在登入頁面輸入帳號與密碼，點擊「登入」按鈕。
3
驗證成功後，系統將自動跳轉至主儀表板頁面。
💡 若忘記密碼，請聯繫系統管理員重新設定。

2. 主介面導覽

圖 1：主儀表板全景 — 左側篩選面板、中央 3D 地圖、右側事件列表、底部播放器

主介面分為四個主要區域：

  • A 左側 篩選與控制面板：地區篩選、時間設定、指標切換。
  • B 中央 3D 地圖畫布：顯示 1,100+ 個微感測站，以顏色標示 PM₂.₅ 濃度高低。
  • C 右側 微感事件面板：系統自動偵測到的超標群聚事件列表。
  • D 底部 歷史播放器：時間軸控制，可播放歷史污染擴散動態。

3. 地圖基本操作

  • 縮放：滑鼠滾輪縮放，或點擊地圖右上角的 +/− 按鈕。
  • 移動視角：按住左鍵拖曳移動地圖，按住右鍵拖曳旋轉 3D 視角。
  • 查看測站資訊：將滑鼠移至任意測站標記上，會彈出資訊視窗 (Popup)，顯示：
    • 測站名稱與行政區
    • 目前 PM₂.₅ 濃度 (µg/m³)
    • 溫度（°C）與濕度（%）
    • 測站運作狀態
📌 地圖上的測站顏色代表 PM₂.₅ 濃度高低：綠色 = 良好（<15）｜黃色 = 普通（15-35）｜橘色 = 不健康（35-54）｜紅色 = 超標（≥54）。超標測站會有動態呼吸燈效果。

4. 篩選功能使用

4.1 地區與工業園區篩選

在左側面板的「第一層：地區或園區」下拉選單中，選取您要觀測的行政區（如大里區）或工業園區（如大里產業園區）。

點選後，地圖相機會平滑飛越至該區域，並自動過濾僅顯示屬於該區的測站。

4.2 時間區間設定

在「開始時間」與「結束時間」欄位輸入您要查詢的歷史時間範圍，這將限制底部播放器的時間軸範圍。

4.3 展示指標切換

點擊左側面板的指標按鈕，可切換地圖上標示的數值：

  • PM₂.₅：懸浮微粒濃度（預設）
  • 溫度：大氣溫度（°C）
  • 濕度：相對濕度（%）

5. 歷史播放器使用

在頁面底部的播放控制列，可以觀看污染隨時間擴散的動態：

  • ▶ 播放 / ⏸ 暫停：點擊播放按鈕開始，地圖上的測站顏色會隨時間軸更新；再次點擊暫停。
  • 時間軸滑桿：拖曳滑桿可直接跳到特定時間點，每格刻度為 5 分鐘。
  • ±5 分鐘步進：點擊播放列右側的循環圖示，可手動前進或後退 5 分鐘。

6. 微感事件列表操作

6.1 查看事件與警示範圍

右側「微感事件」面板列出系統自動偵測的超標群聚事件。每筆事件顯示：

  • 事件標題：若落在工業園區內，會顯示如 大里產業園區-微感事件；否則顯示 微感事件。
  • 觸發時間、超標站數、平均 PM₂.₅、事件狀態。

點擊事件後：

  • 地圖相機自動飛越至事件中心位置。
  • 地圖上出現紅色半透明警示範圍圓圈，標示該次群聚事件的影響半徑。
  • 頁面頂部出現橘色通知橫幅「正在檢視歷史事件：…」。

6.2 查看事件規則

點擊事件標題後方的「規則」小按鈕，會彈出視窗顯示此事件觸發時的系統門檻參數，包含：PM₂.₅ 超標閾值、連續超標筆數、群聚半徑、最少站數。

6.3 關閉通知橫幅與返回即時監測

⚠️ 注意：「關閉橫幅 (X)」與「返回即時監測」是兩個不同操作！

  • 點擊橫幅右側的「X」：僅隱藏頁面頂部的橘色通知橫幅（避免遮擋視野），地圖上的紅色警示圓圈依然保留，您可以繼續觀察影響範圍。
  • 點擊橫幅中的「返回即時監測」：同時清除警示圓圈，並將時間軸回到最新即時時間。若您已點擊 X 關閉橫幅，可在右側事件面板找到「返回即時監測」連結按鈕。

6.4 更新事件狀態

選取事件後，可在右側詳情中更新事件狀態：

  • 待確認：事件已自動產生，尚未有人確認。
  • 調查中：稽查人員已接獲通知，正在實地確認中。
  • 已結案：稽查完成，事件已處理。

7. 門檻設定調整（管理員）

圖 2：事件門檻設定 Modal — 可調整四項系統判定參數

點擊右上角的「事件門檻設定」按鈕開啟設定視窗：

  • PM₂.₅ 濃度閾值 (µg/m³)：超過此值且達連續筆數才算超標，預設 54 µg/m³（AQI 標準紫害等級）。
  • 連續超標判定筆數：避免一次突波導致誤報，預設 3 筆（合計 15 分鐘連續超標）。
  • 群聚半徑 (公里)：超標測站之間的最大聚集距離，預設 1.0 公里。
  • 群聚最少站數：此半徑內至少需要多少超標測站才產生事件，預設 2 站。

調整後點擊「儲存」，系統立即套用新參數並重新計算事件。
