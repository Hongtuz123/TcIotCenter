API 規格文件

系統名稱：微感監測中心 (TC IoT Center) 文件版本：v1.0.0 作者：PST-Tim 日期：2026-07 目標讀者：Backend、Frontend 工程師

總覽

所有 API 路由均位於 /api/* 路徑，由 Next.js App Router Serverless Functions 提供服務。目前版本無 API Key 認證（依靠頁面層 Middleware 保護），建議 v2.0 版本補充 Bearer Token 驗證。

端點Method功能讀者
/api/loginPOST帳號密碼認證Frontend
/api/sensorsGET取得全量測站資料Frontend
/api/observationsGET取得特定時間點觀測值Frontend
/api/anomaliesGET超標群聚判定（非同步寫入事件）Poller / Frontend
/api/clusters-24hGET24小時熱區統計Frontend
/api/completenessGET資料完整率健康指標Frontend / 監控
/api/eventsGET / POST / DELETE事件 CRUDFrontend / Poller
/api/events/[id]GET / PATCH單一事件查詢與狀態更新Frontend
/api/settingsGET / POST系統門檻設定讀寫Frontend
POST/api/login 使用者認證

驗證帳號密碼，成功後設定認證 Cookie，用於 Middleware 的頁面保護。

Request Body

{ "username": "admin", "password": "your_password" }

Response (200 OK)

{ "success": true }

Response (401 Unauthorized)

{ "error": "Invalid credentials" }
GET/api/sensors 取得全量測站資料

返回台中市全部微感測站的靜態基本資訊（名稱、座標、行政區）。

Query Parameters

  },
  ...

GET/api/observations 取得特定時間點觀測值

返回指定時間點（對齊到 5 分鐘桶）所有測站的觀測測值。

Query Parameters

參數類型必填說明
timestring否目標時間 (格式：YYYY-MM-DD HH:mm:00)，不帶則返回最新

Response (200 OK)

[
  {
    "sensor_id": "TC0062",
    "time": "2026-07-14 08:00:00",
    "pm2_5": 23.5,
    "temperature": 31.2,
    "humidity": 75.1,
    "voc": null,
    "isAnomaly": false,
    "score": 0
  },
  ...
]
GET/api/anomalies 超標群聚判定

執行連續超標判定 + Haversine 空間群聚演算法。判定完成後立即回傳結果，自動建立事件的資料庫寫入以非同步 Fire-and-Forget 方式進行，不阻塞回應。

⚡ 效能設計：此 API 回應時間 < 100ms。資料庫寫入在背景非同步執行，呼叫方不需等待。

Query Parameters

參數類型必填說明
timestring否分析時間點，不帶則使用當前時間

GET/api/completeness 資料完整率健康指標

計算過去 1 小時觀測資料完整率，可供監控系統作為 Health Check 端點。

📊 運維建議：當 completeness_rate < 0.7 時，應發送告警通知，代表超過 30% 測站資料缺失。

Response (200 OK)

{
  "completeness_rate": 0.94,
  "total_sensors": 1153,
  "active_sensors": 1084,
  "offline_count": 69,
  "window_start": "2026-07-14T07:00:00Z",
  "window_end": "2026-07-14T08:00:00Z"
}
