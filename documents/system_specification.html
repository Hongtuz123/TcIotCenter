1. 功能群組規劃 (Functional Modules Group)

為了使開發、測試與維運能夠模組化進行，我們將整個微感監測系統切分為五個核心功能群組：

A. 空間與時間控制群組 (Control Center Module)

  • 功能描述：負責首頁左側控制面板，管理地理過濾、主要展示指標與歷史時間範圍設定。
  • 輸入參數：第一層地區（行政區/工業園區名稱）、第二層感測器 ID、開始/結束時間、PM₂.₅ 數值範圍過濾。
  • 輸出與資料流：同步更新全域狀態中的 selectedFilter、startDateTime 與 endDateTime，觸發 Mapbox 與時間軸的連動重新繪製。
  • 關聯後端 API：GET /api/sensors。

B. GIS 3D 地圖展示群組 (GIS Map Module)

  • 功能描述：基於 Mapbox GL JS，實時載入測站並在 WebGL 圖層繪製 PM₂.₅ 濃度熱區密度圖。
  • 地圖圖層管理：
    • sensors-heatmap-layer (熱區密度圖層，不透明度 0.55，動態色彩漸層)。
    • industrial-zones-fill (GeoJSON 園區多邊形圖層，紫色半透明填色與邊線)。
    • active-event-fill-layer (當前選定歷史事件之警示圓圈範圍，紅色半透明，不透明度 0.3)。
    • active-event-outline-layer (當前選定歷史事件之邊界，紅色虛線描邊)。
  • 互動行為：支援地圖 Marker 懸停 Popup 顯示測站即時測值（PM₂.₅、溫度、濕度、狀態、行政區），以及點擊飛越縮放。

C. 歷史播放控制群組 (Timeline Player Module)

  • 功能描述：提供類似影音播放器的時間軸前進與後退控制，驅動地圖載入歷史時間切片的感測器狀態。
  • 狀態處理：在 `Play` 狀態下，設置 `setInterval` 計時器，以 5 分鐘為間隔累加時間，直到觸發結束時間並自動暫停。
  • 關聯後端 API：GET /api/observations?time=...。

D. 微感事件管理群組 (Event & Anomaly Detection Module)

  • 功能描述：系統事件的核心，負責自動偵測、儲存、展示和標註群聚事件。
  • 自動化判定邏輯： poller 定時呼叫後端 API 執行空間與時間超標演算法。判定成立後，後端透過非同步解耦機制，將事件寫入資料庫 events 表中，title 統一儲存為 [自動] 微感事件 (門檻: PM₂.₅ XX)。
  • 前端動態園區命名：事件列表加載時，前端自動讀取事件 bounds 座標，反查最近的測站並依據 GeoJSON 判斷其工業區歸屬，動態冠以 [工業園區名稱]-微感事件 或 微感事件。
  • 關聯後端 API：GET /api/anomalies (判定觸發), GET/POST/DELETE /api/events (事件管理)。

E. 設定與門檻管理群組 (Settings & Config Module)

  • 功能描述：提供使用者調整系統核心警示閾值，參數存於資料庫的 Settings 表，並在後端與前端判定時進行全域套用。
  • 關聯後端 API：GET/POST /api/settings。

2. 資料表 Schema 設計 (Database Schema)

2.1 感測器基本資訊表 (sensors)

欄位名稱 (Column) 型別 (Type) 屬性 (Attributes) 說明 (Comment)
id VARCHAR(50) PRIMARY KEY 設備 DeviceID (例如: TCIOT_001)
name VARCHAR(100) NOT NULL 測站名稱
lat DOUBLE NOT NULL 緯度
lon DOUBLE NOT NULL 經度
county VARCHAR(50) INDEX 縣市行政區名稱 (例如: 大里區)
status VARCHAR(20) DEFAULT '正常' 測站運作狀態 (正常/異常/維護)

2.2 每5分鐘觀測資料表 (observations)

欄位名稱 (Column) 型別 (Type) 屬性 (Attributes) 說明 (Comment)
id BIGINT PRIMARY KEY AUTOINCREMENT 唯一遞增 ID
sensor_id VARCHAR(50) FOREIGN KEY -> sensors(id) 設備外鍵
time TIMESTAMP INDEX (COMPOSITE with pm2_5) 觀測時間點 (每 5 分鐘一期)
pm2_5 FLOAT INDEX (COMPOSITE with time) PM₂.₅ 懸浮微粒濃度 (µg/m³)
temperature FLOAT - 大氣溫度 (°C)
humidity FLOAT - 大氣相對濕度 (%)
voc FLOAT - 揮發性有機物濃度 (ppm)

2.3 微感事件表 (events)

欄位名稱 (Column) 型別 (Type) 屬性 (Attributes) 說明 (Comment)
id VARCHAR(100) PRIMARY KEY 事件唯一 ID
title VARCHAR(200) NOT NULL 事件標題
description TEXT - 事件詳細內容描述 (含超標站數與濃度)
status VARCHAR(20) DEFAULT '待確認' 事件處理狀態 (待確認/調查中/已結案)
bounds TEXT (JSON) - 事件中心座標與半徑
event_time TIMESTAMP - 事件判定或觸發的時間刻度
stations_count INTEGER - 超標感測器總站數
avg_pm2_5 FLOAT - 事件圈範圍內測站的平均 PM₂.₅ 濃度

3. 後端 API 接口規格

Method Endpoint Request Payload Response 說明
GET /api/sensors - Array of Sensor Objects 取得全量測站基本資料
GET /api/observations ?time=YYYY-MM-DD HH:mm:00 Array of Observation Objects 取得特定時間的全部測值
GET /api/anomalies ?time=YYYY-MM-DD HH:mm:00 { clusters: [] } 觸發當前時間超標與群聚計算，異步寫入事件
GET /api/events - Array of Event Objects 取得歷史事件清單（具自動清理機制）
POST /api/settings { pm25_threshold, consecutive_exceeds, ... } { status: 'ok' } 寫入並保存系統門檻設定
