微感監測中心 - 系統規格書

規格與 Schema 設計 (System Specs)

1. 網站架構與導航 (Sitemap)

微感監測中心為 Single Page Application (SPA) 架構，配合 API 動態更新：

  • /login (登入頁)：使用者認證，通過後導向首頁。
  • / (首頁 - 主儀表板)：
    • 空間與時間控制面版
    • Mapbox 3D 地圖核心
    • 微感事件管理與詳情抽屜
    • 歷史播放器控制條
    • 事件門檻設定 Modal 彈窗
  • API 後端路由 (/api/*)：
    • /api/sensors：取得所有感測器基本資訊與座標。
    • /api/observations：取得選定時間刻度的感測器觀測值。
    • /api/anomalies：判定連續超標與空間群聚，並背景觸發自動事件建立。
    • /api/clusters-24h：聚合 24 小時內所有群聚熱區之統計。
    • /api/events：取得/建立/刪除微感事件。
    • /api/settings：設定參數的讀取與寫入。

2. 資料表 Schema 設計 (SQLite / Supabase 對應)

2.1 感測器基本資訊表 (sensors)

欄位名稱 資料型別 主鍵/索引 說明
id VARCHAR PRIMARY KEY 設備 DeviceID (如: TCIOT_001)
name VARCHAR - 測站名稱 (如: 沙鹿國中測站)
lat DOUBLE - 緯度 (Latitude)
lon DOUBLE - 經度 (Longitude)
county VARCHAR INDEX 縣市行政區 (如: 沙鹿區)
status VARCHAR - 測站運作狀態 (正常/維護)

2.2 感測器每5分鐘觀測資料表 (observations)

欄位名稱 資料型別 主鍵/索引 說明
id INTEGER / BIGINT PRIMARY KEY 自動遞增 ID
sensor_id VARCHAR FOREIGN KEY 關聯至 sensors(id)
time TIMESTAMP COMPOSITE INDEX (time, pm2_5) 觀測時間點 (每 5 分鐘一期)
pm2_5 FLOAT COMPOSITE INDEX (time, pm2_5) PM₂.₅ 懸浮微粒濃度 (µg/m³)
temperature FLOAT - 大氣溫度 (°C)
humidity FLOAT - 大氣相對濕度 (%)
voc FLOAT - 揮發性有機物濃度 (ppm)

2.3 微感群聚事件表 (events)

欄位名稱 資料型別 主鍵/索引 說明
id VARCHAR PRIMARY KEY 自動/手動事件 ID (如: auto_202607131130_24.16_120.64)
title VARCHAR - 事件標題 (如: [自動] 微感事件 (門檻: PM₂.₅ 54))
description TEXT - 事件詳細內容描述 (含超標站數與濃度)
status VARCHAR - 事件處理狀態 (待確認/調查中/已結案)
bounds TEXT (JSON) - 事件中心座標與半徑 (如 {"center":{"lat":24.1,"lng":120.6},"radiusKm":1.0})
event_time TIMESTAMP - 事件判定或觸發的時間刻度
stations_count INTEGER - 超標感測器總站數
avg_pm2_5 FLOAT - 事件圈範圍內測站的平均 PM₂.₅ 濃度
created_at TIMESTAMP - 事件建立時間
updated_at TIMESTAMP - 最後更新時間

2.4 系統閾值設定表 (settings)

欄位名稱 資料型別 主鍵/索引 說明
key VARCHAR PRIMARY KEY 設定鍵名 (如: pm25_threshold, consecutive_exceeds)
value VARCHAR - 設定值 (字串型式儲存)
updated_at TIMESTAMP - 最後修改時間

3. 介面 Prototype 設計與關鍵元件說明

  • Sidebar (篩選面板)：大片深色背景玻璃卡片 (CSS glass-card)，利用橘色 (#f97316) 作為邊線亮點與點選焦點狀態。
  • Map Canvas (地圖容器)：Mapbox DOM 佔滿背景，Marker 使用高度客製化的 React/CSS 圓點，透過 CSS keyframe 實現超標點位呼吸燈 (Glow) 與擴散圈 (Radar-Ping) 動態效果。
  • Timeline (播放組件)：底部橘色播放滑桿配合 Lucide 的 Play/Pause 開關，藉由 HTML5 Range Input 自訂 CSS Track 完成極具現代感的播放軌道。
