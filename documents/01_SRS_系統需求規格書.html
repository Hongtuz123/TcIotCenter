系統需求規格書 (SRS)

系統名稱：微感監測中心 (TC IoT Center) 文件版本：v1.0.0 作者：PST-Tim 日期：2026-07 目標讀者：PM、SA、開發工程師

1. 系統概述

微感監測中心是一套即時環境空氣品質監測與異常事件自動偵測平台，整合台中市 1,100+ 個微感測站的 PM₂.₅、溫度、濕度觀測資料，透過 3D Mapbox 地圖進行視覺化呈現，並內建空間群聚演算法自動判定污染熱區、產生微感事件，供環保稽查人員使用。

1.1 主要目標

  • 提供 即時（每 5 分鐘更新）的 PM₂.₅ 空間分佈熱區地圖。
  • 自動偵測連續超標+空間群聚事件，降低人工稽查的盲目性。
  • 提供歷史時間軸播放功能，支援事後污染路徑分析。
  • 依據產業園區 GeoJSON 邊界自動標註污染源所屬園區。

1.2 系統邊界

ℹ️ 系統邊界說明
本系統屬於展示與決策支援平台，並非直接控制感測設備的 SCADA 系統。資料來源為環境部 OGC SensorThings API，本系統不擁有感測器，僅負責資料接入、分析與視覺化。

3. 功能性需求 (Functional Requirements)

FR-01：GIS 地圖展示

  • FR-01-1：系統應在主頁面顯示台中市全域 3D Mapbox 地圖，並載入 1,100+ 個微感測站標記。
  • FR-01-2：測站標記應依 PM₂.₅ 濃度顯示對應顏色（綠/黃/橘/紅），超標測站應顯示呼吸燈動畫效果。
  • FR-01-3：系統應在地圖上疊加 PM₂.₅ 熱區密度圖層（Heatmap Layer），不透明度 0.55。
  • FR-01-4：系統應在地圖上疊加產業園區 GeoJSON 多邊形圖層（紫色半透明填色）。
  • FR-01-5：使用者點擊測站標記時，應彈出 Popup 顯示：站名、PM₂.₅、溫度、濕度、狀態、行政區。

FR-02：空間與時間篩選

  • FR-02-1：提供行政區下拉選單，點選後地圖相機應飛越至對應區域中心，並過濾點位顯示。
  • FR-02-2：提供工業園區下拉選單，功能同 FR-02-1。
  • FR-02-3：提供特定測站 ID 篩選輸入框。
  • FR-02-4：提供歷史時間區間（開始時間、結束時間）設定輸入。

FR-03：歷史播放器

  • FR-03-1：提供播放 / 暫停控制，以 5 分鐘為最小刻度依序載入歷史觀測快照。
  • FR-03-2：提供時間軸滑桿，支援使用者隨意拖曳至特定時間點。
  • FR-03-3：提供 ±5 分鐘快速步進按鈕。

FR-04：異常事件自動偵測

  • FR-04-1：系統應每 5 分鐘自動執行連續超標判定，僅當測站連續 N 筆（可設定）PM₂.₅ ≥ 閾值時，才標記為超標種子點。
  • FR-04-2：系統應對超標種子點執行 Haversine 空間群聚演算法，當半徑 R 內站點數 ≥ 最少站數時，產生群聚事件。
  • FR-04-3：事件應依據產業園區 GeoJSON 邊界動態命名（如 大里產業園區-微感事件 或 微感事件）。
  • FR-04-4：選取事件後，地圖應顯示紅色半透明警示範圍圓圈（不透明度 0.3）。

FR-05：事件管理

  • FR-05-1：右側面板應列出所有歷史事件清單，顯示：標題、時間、狀態、平均 PM₂.₅、超標站數。
  • FR-05-2：點擊「規則」按鈕應彈出該事件觸發時的系統門檻參數。
  • FR-05-3：管理員可手動更新事件狀態（待確認 / 調查中 / 已結案）。
  • FR-05-4：管理員可刪除事件。

FR-06：系統門檻設定

  • FR-06-1：管理員可調整 PM₂.₅ 超標閾值（µg/m³）。
  • FR-06-2：管理員可調整連續超標判定筆數（N 筆 × 5 分鐘）。
  • FR-06-3：管理員可調整群聚半徑（公里）。
  • FR-06-4：管理員可調整群聚最少站數。

⚠️ 現階段實作說明

v1.0 版本使用單一帳號密碼認證（/api/login），尚未實作多角色 JWT 分級。RBAC 矩陣為設計目標，v2.0 版本建議導入 Supabase Auth + Roles 或 NextAuth.js 實現。

7. 系統限制與假設

  • 資料來源依賴環境部 OGC SensorThings API 服務可用性，若外部 API 故障，新資料將停止更新。
  • 地圖渲染需要瀏覽器支援 WebGL（IE 不支援，建議 Chrome/Edge 最新版）。
  • Vercel Hobby 方案 Serverless Function 執行時間上限為 10 秒，已透過非同步解耦確保在此限制內。
  • SQLite 為本地單一節點資料庫，不支援多實例並發部署，僅適用於單機部署場景。
